# SystemicMinds Solutions Inc. — sitio corporativo

Página web estática (HTML + CSS + Bootstrap 5 + JS) de la empresa ficticia
**SystemicMinds Solutions Inc.**

## Cómo verla en local

Abre `index.html` en el navegador, o desde esta carpeta:

```bash
npx serve .
# o: python3 -m http.server 5500
```

## Desplegar en otro repo

1. Crea un repo nuevo (GitHub Pages / Netlify / Vercel).
2. Sube el contenido de esta carpeta `pagina-web/` como raíz del repo.
3. Publica `index.html`.

## Estructura

```
pagina-web/
├── index.html
├── css/estilo.css
├── js/app.js
├── assets/logo.png
└── README.md
```
